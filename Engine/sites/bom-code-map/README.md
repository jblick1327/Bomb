# BOM Code Atlas

A buildless interactive guide to the 15 application files in `src/`. Open `dist/index.html` directly in a browser. All interactions run locally; fonts have system fallbacks.

The map describes responsibilities and conceptual relationships, not imports: all files are in the same Odin package. Guided paths cover authoring, blasts, and frame rendering. Source excerpts and counts are a snapshot of the repository on November 3, 2026.

Source counts exclude unit tests, smoke/soak helpers, fixtures, benchmarks, and archives. Counts include blanks and comments. No game source is changed.
